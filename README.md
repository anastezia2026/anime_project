# 🌸 Аниме-Портал (Anime Portal)

Веб-приложение для поиска, подбора и отслеживания любимых аниме-сериалов. Проект помогает пользователям находить новые тайтлы на основе их интересов, сохранять их в персональные списки и находить вдохновляющие цитаты из любимых произведений.

> 💡 **Идея проекта:** Создать удобный инструмент, который не просто выдает список аниме, а помогает сделать осознанный выбор на основе жанров и рейтингов, а также позволяет вести личный дневник просмотров.

---

## ✨ Основные возможности

- 🏆 **Топ аниме:** Просмотр лучших тайтлов с высоким рейтингом (данные обрабатываются и фильтруются через библиотеку **Pandas**).
- 🎯 **Подбор по интересам:** Умная система рекомендаций, которая ищет аниме по выбранным пользователем жанрам через внешнее API.
- 🔍 **Поиск по названию:** Быстрый поиск любого аниме с выводом постера, описания и ссылки на подробную информацию.
- 💬 **База цитат:** Поиск вдохновляющих фраз по названию аниме (реализован через чтение и фильтрацию локального **JSON**-файла с помощью **Pandas**).
- 👤 **Личный кабинет:** 
  - Регистрация и безопасный вход в систему.
  - Управление персональными списками: *"Хочу посмотреть"*, *"Смотрю"*, *"Просмотрено"*.
  - Данные пользователей надежно хранятся в реляционной базе данных **SQLite**.

---

## 🛠 Стек технологий

Проект разделен на бэкенд и фронтенд с четким разделением ответственности:

| Категория | Технологии |
| :--- | :--- |
| **Язык** | Python 3.x |
| **Бэкенд (Web)** | Flask (маршрутизация и логика) |
| **Обработка данных** | Pandas (фильтрация, сортировка, анализ таблиц) |
| **Работа с сетью** | Requests (получение данных из Kitsu API) |
| **База данных** | SQLite3 (хранение пользователей и их списков) |
| **Форматы данных** | JSON (локальное хранение цитат) |
| **Фронтенд** | HTML5, CSS3, Bootstrap 5 (адаптивный дизайн) |
| **Контроль версий** | Git, GitHub |

## 📂 Структура проекта

```text
anime_project/
│
├── app.py                  # Главный файл приложения (логика Flask, роуты, функции)
├── quotes.json             # Локальная база данных цитат (50+ фраз)
├── anime.db                # Файл базы данных SQLite (создается автоматически)
├── requirements.txt        # Список зависимостей (можно создать через pip freeze)
│
├── templates/              # HTML-шаблоны (фронтенд)
│   ├── base.html           # Базовый шаблон с навигацией
│   ├── index.html          # Главная страница
│   ├── top.html            # Страница топа аниме
│   ├── recommend.html      # Страница подбора по жанрам
│   ├── search.html         # Страница поиска по названию
│   ├── quotes.html         # Страница поиска цитат
│   ├── login.html          # Страница входа
│   ├── register.html       # Страница регистрации
│   └── profile.html        # Личный кабинет пользователя
│
└── static/                 # Статические файлы
    └── style.css           # Дополнительные стили оформления
Как запустить проект локально
Склонируйте репозиторий:
git clone https://github.com/anastezia2026/anime_project.git
cd anime_project
Создайте и активируйте виртуальное окружение
   # Для Windows
   python -m venv .venv
   .venv\Scripts\activate
Установите необходимые библиотеки:
   pip install flask pandas requests
Запустите приложение
   python app.py
